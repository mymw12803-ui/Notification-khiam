# منظومة الإشعارات ومتابعة الموظفين

لوحة تحكم (داشبورد) لإرسال إشعارات وإنذارات ومخالفات وطلبات رد للموظفين، تظهر لهم في **أي تبويب يعملون عليه**، مع متابعة لحظية لحالة كل موظف: يعمل على ميتا بيزنس، على يوتيوب، خارج المتصفح، خامل، أو انقطع الإنترنت — وقياس سرعة الرد.

| المجلد | المحتوى |
|---|---|
| `server/` | الخادم + الداشبورد (Node.js) |
| `extension/` | إضافة كروم التي تُثبَّت عند الموظفين |
| `store/` | صور ونصوص صفحة الإضافة في متجر كروم |
| `render.yaml` | إعداد النشر بضغطة على Render |
| `Dockerfile` | للنشر على Railway / Fly.io / أي سيرفر |
| `build.js` | يحزّم الإضافة في ملف zip للمتجر |

---

## الحصول على رابط للداشبورد (النشر على الإنترنت)

> **مهم:** GitHub يحفظ الكود فقط ولا يشغّله. الداشبورد يحتاج سيرفر يعمل باستمرار (لأن الإضافات متصلة به لحظياً)، لذلك نربط المستودع بخدمة **Render** فتعطيك رابطاً مثل `https://notifications-dashboard.onrender.com`.

1. ارفع محتويات هذا المجلد إلى مستودع جديد على GitHub (يفضل **Private**).
2. ادخل <https://dashboard.render.com> وسجّل بحساب GitHub.
3. اضغط **New ← Blueprint** ← اختر المستودع ← سيقرأ `render.yaml` تلقائياً.
4. سيطلب منك قيمة **`ADMIN_PASSWORD`**: اكتب كلمة مرور قوية للوحة التحكم.
5. اضغط **Apply**. بعد دقيقتين تقريباً يظهر رابط الخدمة أعلى الصفحة — هذا هو رابط الداشبورد.

**التكلفة:** الإعداد يستخدم خطة **Starter (حوالي 7$ شهرياً) + قرص 1GB (حوالي 0.25$)**.
الخطة المجانية لا تصلح لهذا النظام لسببين: تنام بعد 15 دقيقة فتنقطع إشعارات الموظفين، وليس فيها قرص دائم فتُمسح بيانات الموظفين وأكوادهم مع كل إعادة تشغيل.

**نسيت كلمة المرور؟** في Render ← Environment: غيّر `ADMIN_PASSWORD` وأضف متغيراً `ADMIN_PASSWORD_RESET=1` ← أعد التشغيل ← ادخل ← احذف `ADMIN_PASSWORD_RESET`.

### بدائل
- **Railway / Fly.io / VPS:** استخدم `Dockerfile` واربط قرصاً دائماً على المسار `/data`.
- **مجاناً من جهازك:** شغّل `تشغيل الخادم.bat` ثم `cloudflared tunnel --url http://localhost:3000` (يجب أن يبقى جهازك يعمل).

## إضافة الموظفين (متجر كروم)

1. شغّل: `node build.js https://رابط-الداشبورد` ← يُنشئ ملف zip للإضافة **ومكتوب بداخله رابط الداشبورد**، فلا يحتاج الموظف إلا لإدخال كوده.
2. افتح <https://chrome.google.com/webstore/devconsole> (رسوم تسجيل لمرة واحدة 5$) ← **New item** ← ارفع ملف zip.
3. املأ صفحة المتجر من `store/listing.md` وارفع الصور الموجودة في `store/`.
4. اختر الظهور **Unlisted** (غير مدرج: لا يظهر في البحث، يثبّته فقط من معه الرابط) ← Submit for review.
5. بعد الموافقة أرسل الرابط للموظفين ← «إضافة إلى Chrome» ← يدخل كوده من صفحة «الموظفون» في الداشبورد.

رابط سياسة الخصوصية المطلوب في المتجر: `https://رابط-الداشبورد/privacy`

## التشغيل المحلي (للتجربة)

```bash
cd server
npm install
node server.js
```
ثم افتح `http://localhost:3000` (كلمة المرور الأولى `admin`). تفاصيل أكثر في [دليل التشغيل](دليل%20التشغيل.md).

## المتغيرات

| المتغير | الوصف |
|---|---|
| `PORT` | منفذ الخادم (افتراضي 3000) |
| `DATA_DIR` | مجلد البيانات (افتراضي `server/data`) |
| `ADMIN_PASSWORD` | كلمة مرور اللوحة عند أول تشغيل |
| `ADMIN_PASSWORD_RESET` | `1` لإعادة ضبط كلمة المرور من `ADMIN_PASSWORD` |
| `PUBLIC_URL` | الرابط العام (يُكتشف تلقائياً على Render) |
